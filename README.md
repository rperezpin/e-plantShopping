# E-Plant 🌱  

E-Plant is a React-based web application designed for plant lovers. It provides an interactive interface to explore different plant categories, including air-purifying plants, aromatic plants, insect-repellent plants, medicinal plants, and low-maintenance plants.  

## 🚀 Features  

- **Landing Page**: A welcoming screen with an introduction to Paradise Nursery.  
- **Dynamic Product List**: Users can browse through different plant categories.  
- **State Management**: Uses Redux for managing application state.  
- **Modular Components**: Organized structure with reusable React components.  

## 🔧 Technologies Used  

- React.js  
- Redux  
- Vite  
- CSS for styling  

## 📌 Main Components  

- `App.jsx` → Main application component that handles navigation between landing page and product list.  
- `ProductList.jsx` → Displays the list of plants available.  
- `AboutUs.jsx` → Provides information about Paradise Nursery.  
- `store.js` → Configures Redux store for state management.  

## 🏁 Installation and Execution  

1. Clone the repository:  
   ```bash
   git clone https://github.com/rperezpin/e-plant.git
   cd e-plant
   ```
2. Install dependencies:  
   ```bash
   npm install
   ```
3. Start the development server:  
   ```bash
   npm run dev
   ```
4. Open the application in your browser at `http://localhost:5173`
